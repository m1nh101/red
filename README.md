## 🎯 Purpose

The goal of this repository is to:

- Keep track of my pentesting knowledge.
- Document CTF solutions and attack paths.
- Record commands, techniques, and useful references.
- Review concepts that I have previously learned.
- Share useful notes with others who are learning pentesting.

## 🏴 CTF Write-ups

Each write-up focuses on the **enumeration and reasoning process**, rather than simply providing the final solution.

A typical write-up covers:

```text
Reconnaissance
      ↓
Enumeration
      ↓
Vulnerability Identification
      ↓
Exploitation
      ↓
Initial Access
      ↓

      ↓
Root / Administrator
```
